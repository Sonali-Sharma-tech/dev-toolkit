## Quick Commands

### npm
```bash
npm install           # Install dependencies
npm run dev           # Run dev script
npm outdated          # Check for updates
```

### Homebrew
```bash
brew install <pkg>    # Install package
brew upgrade          # Update all
brew list             # See installed
```

## Which One?

| Task | Use |
|------|-----|
| JavaScript dependencies | npm/yarn/pnpm |
| macOS CLI tools | Homebrew |
| macOS GUI apps | Homebrew Cask |
| Python packages | pip |
| Global dev tools | Homebrew (preferred) |
